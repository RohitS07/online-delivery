# Glossary

One definition per term. If two artefacts disagree, this file wins.

| Term | Means |
|---|---|
| **Artefact** | One document with a stable id and a status: an ADR, BPM, US, SPEC, NFR, RULE, SKILL, PROC or EVAL. |
| **Acceptance criterion** | One testable condition of a story, bound to the test or eval that checks it. |
| **Service date** | The IST calendar date that stock and orders belong to. |
| **Order window** | The time on a service date when customers can order, from the open time to the close time. Defaults 8:00 and 18:00 IST. |
| **Village agent** | The one approved delivery agent of a village. Each agent serves exactly one village. |
| **Delivery hours** | Hours added to the close time to give a village's expected delivery time. Set per village by an admin. |
| **Delivery fee** | A fixed amount added to every order for the agent. Default ₹90. |
| **Platform fee** | A fixed amount added to every order for the platform. Default ₹10. |
| **Registration token** | A short-lived token proving a person holds a mobile number that has no account yet. It allows sign-up only. |
